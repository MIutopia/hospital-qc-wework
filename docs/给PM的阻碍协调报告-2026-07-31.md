## 三、核心阻碍详解

### 阻碍 1（当前必须解决）：企微「可信 IP」白名单拦截 — errcode=60020

- **现象**：2026-07-31 用测试工具实测企微通讯录接口，`department/list`（枚举部门）与 `user/get`（拉指定成员）均返回：
  `errcode=60020, errmsg=not allow to access from your ip`
- **原因**：企微管理后台为该应用配置了「企业可信 IP」白名单，测试机器公网 IP 不在白名单内。
- **影响**：无法从企微拉取任何成员信息 → 医生-企微映射（2.4）无法建立 → 后续 M4 推送无接收人。
- **需要 PM 协调**：请企微管理员在**企微管理后台 → 应用管理 → 应用 → 企业可信IP**，添加**部署服务器**的公网 IP（本系统单机部署，应用最终运行在哪台服务器就加哪台的 IP）。加白后在该机器上复测即可。
- **⚠️ 关键前置（2026-08-03 确认）：** 企业微信应用**添加「企业可信IP」的前提是必须先添加/配置可信域名**（企微管理后台 → 应用 → **网页授权及JS-SDK → 可信域名**，完成域名归属验证）。域名未配置时可信IP无法生效，需先完成域名添加后再做 IP 加白。
- **备选**：若短期无法加白，可借用任何一台已加白的机器执行一次成员导出（工具支持导出清单），再拿回开发环境处理。

### 阻碍 2（待验证）：通讯录「读取成员」权限 — 可能 errcode=60011

- **现状**：当前用的是质控应用自身的 `agent_secret`，默认可能只读应用自身数据，不保证能读全企业通讯录。
- **需要**：给应用勾选「通讯录-读取成员」权限；或改用「我的企业 → 通讯录同步」中的**通讯录同步 secret**。
- **验证方式**：IP 加白后再跑一次测试工具，若返回 60011 即进入此步骤。

### 阻碍 3（原方案，可绕过）：信息科医生通讯录 CSV 未交付

- 原方案依赖信息科导出医生通讯录 CSV；现已改为**企微通讯录 API 直拉优先**，解除阻碍 1+2 后不再强依赖 CSV，信息科工作量可减负。
